This is the unmodified public Python documentation link index, containing
object names and URLs rather than documentation prose. Keeping it locally
lets Sphinx validate and link standard-library types in offline builds.

To refresh it, download the source URL to python.inv, update the retrieval
date and SHA-256 above, and run the full offline gate (uv run poe check).
An ordinary documentation build must never download this file.
